# EadoPlay 项目说明

## 项目定位

EadoPlay 是针对 **2018 款长安逸动原厂 Android 4.4.2 车机**维护的社区 CarPlay 兼容项目，重点是在不更换原厂车机的前提下，改善无线 CarPlay 的连接、音视频、方向盘按键和通话体验。

本项目基于 DiPlay、DiPlay-Legacy-Android 及其上游 xcertplay 修改，不是 Apple、长安汽车、Carlinkit 或上游维护者的官方产品。

## 当前版本重点

- 适配 Android 4.4.2 和目标车机的旧版音视频、网络及后台运行环境；
- 使用车机热点完成无线 CarPlay 连接；
- 支持导航、音乐、触控和方向盘媒体按键；
- 适配系统电话接听与挂断；
- 处理原车蓝牙在无线交接后反向暂停音乐的问题；
- 车辆重新启动导致蓝牙恢复时，自动再次处理相关通道；
- 提供音乐与导航独立软件音量，并保留导航播报时降低音乐音量；
- 提供连接阶段、音视频和麦克风诊断信息；
- 移除与长安逸动无关的 BYD HUD、仪表和后台集成。

## 已验证与已知限制

无线 CarPlay 的导航、触控、音乐、方向盘按键、系统电话，以及锁屏状态下的微信来电已经过目标车辆实测。

当前已知限制：

- iPhone 锁屏时，从 CarPlay 主动拨出的微信语音可能无声，点亮手机后恢复；
- 有线 CarPlay 仍停留在目标车机的 Android USB Host 授权阶段，尚未完成端到端验证；
- 不同年份、配置或固件的长安车机可能具有不同权限、蓝牙服务和音频路由，不能仅凭 Android 版本判断兼容性。

## 默认使用建议

- 优先使用经过实车验证的无线热点模式；
- 老车机优先选择 30 帧和 SurfaceView，以稳定性为先；
- 只保留一个 CarPlay 接收程序运行，避免蓝牙、网络端口和音频焦点冲突；
- 首次使用或出现故障时保存诊断报告，再根据具体失败阶段排查；
- 安装与调试必须在车辆安全停放时进行。

## 维护原则

- 实车验证优先于模拟器推测；
- 不为缩短几秒连接时间而跳过配件认证或无线交接确认；
- 不通过长期禁用原车安全、蓝牙或语音服务换取表面可用；
- 新改动必须尽量可回退，并避免破坏当前稳定功能；
- 诊断日志不记录通话音频、协议载荷、认证私钥或真实配对记录；
- 公开源码、发布包和第三方内容遵守相应开源许可、来源说明与免责声明。
